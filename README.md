# Nathoeng Community

หน้าศูนย์กลาง https://nathoeng.com เชื่อมเว็บไซต์วัดพุทธอุทยานนาเทิงกับโครงการธรรมะ ห้องสมุด โรงเรียน กฐิน และระบบยืมอุปกรณ์

เว็บไซต์ใช้ HTML และ CSS โดยตรง ไม่ต้องติดตั้งแพ็กเกจ ไม่ต้อง build และไม่มีไฟล์ JavaScript หรือการเปลี่ยนฐานข้อมูล

- `index.html`: เนื้อหา เมนู ลิงก์โครงการ และข้อมูล SEO
- `style.css`: รูปแบบที่รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์
- `assets/`: ภาพและตราวัดที่ปรับขนาดจากเว็บไซต์วัด พร้อม favicon เดียวกับวัด
- `vercel.json`: การตั้งค่าเว็บไซต์แบบ static สำหรับโปรเจ็กต์ nathoeng-community ที่มีอยู่แล้ว

เมื่อแก้ไขลิงก์บริการ ให้รักษา URL และ hash ของเว็บไซต์ปลายทางตามระบบจริง ส่วนระบบบัญชีเป็นลิงก์สำหรับผู้ได้รับสิทธิ์ การตรวจสอบสิทธิ์ยังดำเนินการในเว็บไซต์บัญชี

หน้าแรกประชาสัมพันธ์งานกฐินวันที่ 7–8 พฤศจิกายน 2569 ควรปรับข้อความเมื่อผ่านวันงาน
